# Livrarias para Baicho

Projeto de uma livraria virtual simples, importado de [Livrarias-para-baicho-trabalho](https://github.com/luizotaviop2011-hub/Livrarias-para-baicho-trabalho).

## Executar o site

Abra `index.html` em um navegador. O catálogo, carrinho e fluxo de finalização são executados no navegador com `script.js` e `style.css`.

## Google Apps Script (opcional)

`apps-script.gs` contém o código de integração com uma planilha Google. As instruções de implantação e o formato esperado da planilha estão nos comentários no início do arquivo. Esse arquivo não é necessário para abrir o site estático.
